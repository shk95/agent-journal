# Agent Journal

Agent Journal is a personal work journal for Codex. It records the requests, progress, and results of sessions across your work machines and puts them in one place. Register a GitHub repository once, then keep using Codex as usual.

Keep the terminal journal open beside Codex to follow a project's current work. Open the web journal to see activity across projects, inspect a turn's transcript, or revisit a decision.

- **Journey** follows requests and results through concurrent and forked sessions.
- **Turn notes** preserve thoughts next to the turn that prompted them.
- **Project notes** keep ideas and plans you want to revisit on their own.

Ask Codex to read the relevant parts of the journal or attach a note to a specific turn.

A central server keeps the journal in sync across machines. The observer collects records and coordinates summaries on each work machine, outside the working Codex session.
